# MN Writer

MN Writer 是运行在 MarginNote 5 场景面板中的写作工具。当前学习集的卡片插入正文以后，卡片保留标题、摘录、批注、图片、手写笔迹、页码、标签与引用键。正文支持标题、列表、表格、任务列表、脚注与交叉引用。字数统计面板按 Word 的口径给出字数、字符数与篇幅估算。

写作台在段落之间提供证据支持。正文段落下方会浮出证据条，按相关程度给出学习集里的卡片与原文片段；侧栏的 `相关` 标签页展示当前上下文、相关卡片、资料库候选、联想、引用出处与资料库材料；卡片之间可以沿着文献、标签与内容相近的线索互相跳转。选中文字以后还可以打开段落助手，助手依据学习集里的卡片给出建议，并沿用文稿已有的术语写法。作者可以评价检索结果，资料库中尚未纳入学习集的材料也能按当前段落检索出来，或者在段落缺料时主动出现在候选清单里。大纲面板给出每一节的证据覆盖，卡片的使用记录跨文稿累积。

工程由 MN Rails 2.0.4 创建，使用 React 19、TypeScript、Vite 与 Tiptap。

## 使用

### 插入卡片

可用入口包括：

- 顶栏 `插入卡片` 按钮。
- 正文空行输入 `/`，选择 `插入卡片`。
- 从侧栏卡片列表拖动卡片到正文。

macOS 使用 `⌘K`，Windows 使用 `Ctrl+K`，快速打开卡片选择器。

卡片属于块级内容，插入位置位于当前段落、列表或标题之后。插入完成以后，正文出现一张卡片与一个空段落，光标落在空段落中，可以直接继续写作。

### 斜杠菜单

正文空行输入 `/` 打开命令菜单。菜单的最大高度是 320 像素，面板剩余空间不足时菜单收缩到可用高度，命令在菜单内部滚动。

菜单与面板边缘保留 12 像素，与光标所在行保留 10 像素。下方空间不足时菜单翻转到光标行的上方。

命令超出可见范围时，可以继续滚动的方向出现渐变。滚到尽头以后，该方向的渐变消失，另一个方向的渐变出现。

### 卡片视图

顶栏提供 `完整` 与 `简洁` 显示方式。简洁视图将卡片压缩为一行，只保留标题与摘录。所属文档与引用键在完整视图中呈现。点击行内展开按钮以后，卡片显示完整内容，同时显示卡片类型。卡片视图的选择保存在本地。

完整视图中，长摘录提供 `展开全文` 入口。

### 已插入状态

侧栏与卡片选择器会标记正文已经使用的卡片，并显示引用次数。重复插入时，提示会给出正文中的引用总数。

卡片列表会隐藏与标题重复的摘录和来源。笔记卡只显示标题、页码与有效标签，避免同一信息重复出现。

### 当前选中卡片

在 MarginNote 脑图中选中一张或多张卡片以后，写作台会把这些卡片置于侧栏列表与卡片选择器的首位，并标注 `当前`。多张卡片按原有顺序排列。

混合形态插件通过原生模块读取脑图选区，选区变化由 MarginNote 的选择通知推送。读取失败时，写作台回落到界面状态接口，轮询在页面不可见或者专注模式开启时暂停。

### 卡片定位

双击正文卡片，MarginNote 会切换到对应的卡片。卡片菜单中的 `在 MarginNote 中定位` 提供同样的行为。

### 刷新卡片内容

文稿标题旁的刷新按钮会更新正文内的全部卡片，并重新读取侧栏卡片列表。同一张卡片在正文出现多次时，各处同时更新。刷新期间按钮图标旋转，完成以后提示 `已刷新所有卡片内容`。

### 复制卡片内容

卡片右上角的复制按钮把摘录与批注写入剪贴板，各段之间保留段落。目标程序支持富文本时，粘贴结果保留段落结构；只支持纯文本时，写入纯文本。复制引用仍在卡片菜单中。

### 转为文本

卡片菜单中的 `转为文本` 会把卡片替换为正文段落，只保留标题、摘录与批注。同一段内容在卡片里出现多次时只写入一份。来源标题、页码、标签与引用键不再保留，该操作可以撤销。

卡片具备引用键时，菜单中的 `转为引用` 会把卡片替换为正文段落，并在末尾追加 Pandoc 引用，例如 `[@引用键, p. 3]`。

### 文稿大纲

侧栏 `大纲` 标签列出正文的一级至三级标题。点击标题以后，写作台跳转到对应位置，标题短暂高亮。标题右侧的证据标记给出该节的卡片数量。

### 表格

输入斜杠以后选择 `表格`，正文插入三行三列的数据表。光标位于单元格时可以继续输入文字、设置加粗与插入脚注。表格的列线支持拖动，用于调整列宽。Markdown 导出保留为管道表。

### 任务列表

输入斜杠以后选择 `任务列表`，正文插入可勾选的待办事项。勾选状态保存在文稿里，按回车新增待办事项，按 Tab 缩进形成子任务。导出 Markdown 时，已完成项写作 `- [x]`，未完成项写作 `- [ ]`。

### 脚注

输入斜杠以后选择 `脚注`，光标处插入带编号的引用。点击编号以后，面板底部弹出编辑浮层，填写内容并保存。脚注正文保存在引用节点内部，导出 Markdown 时输出 `[^1]` 与文末定义，导出 JSON 时随文稿一起保存。

### 交叉引用

输入斜杠以后选择 `交叉引用`，面板按标题与表格分区列出可引用的目标。方向键切换，回车插入。点击正文中的引用会滚动到目标位置；目标删除以后，点击给出提示。导出 Markdown 时，标题引用链接到标题锚点，表格引用链接到正文写入的表格锚点。

### 字数统计

顶栏显示当前字数。点击字数打开统计面板，面板列出字数、字符数、中文字符、外文单词、段落、行、页、卡片、脚注、表格与图片。中文按字计，外文按词计。行数与页数按每行 38 个字符、每页 36 行估算。

### 专注模式

macOS 使用 `⌘⇧F`，Windows 使用 `Ctrl+Shift+F`，进入或退出专注模式。`Esc` 退出专注模式。

### 主题与保存

顶栏主题菜单提供 `跟随系统`、`浅色` 与 `深色` 选择。写作台在正文编辑后自动保存到本地。本地存储不可用时，状态栏显示 `本地保存失败`，并提示导出 JSON 备份。

macOS 使用 `⌘S`，Windows 使用 `Ctrl+S`，立即保存当前文稿。

### 导出与恢复

顶栏导出菜单提供 Markdown 复制、Markdown 下载与 JSON 备份。JSON 备份包含正文、卡片快照与排版属性。

`从 JSON 恢复` 读取导出的 JSON 备份，并创建新的文稿。恢复操作不会覆盖当前文稿。导入文稿与现有文稿同名时，标题自动追加序号。

### 引用键

引用键来自 Zotero。Zotero 插件从 Better BibTeX 读取每个条目的引用键，并按文件内容算出 MarginNote 文档标识。文献卡按条目键匹配，摘录卡按文档标识匹配所属文献。

写作台优先向本机的 Zotero 插件读取引用键索引，索引带有抓取时间，十分钟内重复使用缓存。读取失败时退回 Zotero Connector 插件写入的共享缓存。共享缓存与本机索引都没有记录时，引用键取自标签中的 `cite:` 前缀。

### 面板尺寸

右下角的尺寸手柄支持拖动与短按。拖动用于自由调整尺寸，短按在预设尺寸之间循环切换，键盘方向键按 40 像素微调。尺寸保存在本机，重新打开面板时恢复。面板与顶部的拖拽条一并避开场景顶栏，尺寸上限按当前场景的可用空间计算。

### 证据条

光标停在某一段落时，段落下方浮出一条证据条。证据条列出与当前段落相关的卡片，收起时显示张数与最相关的一张卡片标题，展开后给出每张卡片的原文片段、来源、页码与引用键。

相关度按字段区分权重，标题与标签高于摘录与批注；词的稀有度用逆文档频率衡量，出现在大量卡片里的词几乎不参与打分。已经在正文里出现过的卡片不再提示。

片段里与当前段落相同的词标出底纹，作者据此看出卡片被推荐的原因。

证据条上的加号把卡片插入光标处，箭头按钮把 MarginNote 切换到对应的卡片。条目末尾的按钮用来评价检索结果。

### 证据反馈

标记为有用的卡片排在前面，标记为没用的卡片降到末尾。再次点击同一个按钮可以取消标记。判断保存在当前文稿里，不影响其他文稿。相关面板中的卡片会显示同样的标记。

### 相关面板

侧栏的 `相关` 标签页展示五部分内容：

- 当前上下文：所在标题与当前段落。
- 相关卡片：按相关程度排列，附带原文片段、命中词、来源与使用痕迹。
- 资料库候选：段落里的关键内容学习集没有覆盖时，列出的库外材料。
- 联想：由命中的卡片出发，沿关联再走一跳的材料。
- 引用出处：当前所在节写下的引用，逐条给出出处状态。

另有 `资料库材料` 一栏，按当前段落检索整个 MarginNote 资料库的结果。

相关卡片的元信息分两行：第一行是来源标题，第二行是引用键与标记。引用键较长时省略，标记始终完整可见。侧栏、卡片选择器与相关卡片弹层只上下滚动，长标题与长引用键不会让界面横向滚动。

引用扫描识别以下写法：Pandoc 形式的 `[@引用键]` 与 `[@引用键, p. 12]`；括号内的作者年份，例如 `（张三，2020）`、`(Smith, 2023)`；叙述形式的作者年份，例如 `张三（2020）`、`Smith et al. (2023)`。

### 卡片类型与竖线

折叠状态的卡片不显示类型标识。侧栏的卡片列表、相关面板的相关卡片、正文里折叠的卡片、卡片选择器与相关卡片弹层都不显示类型。只有正文里展开的卡片显示类型，作者在此处需要区分卡片的来源。

卡片类型由竖线颜色区分。摘录卡是蓝色，文献卡是琥珀色，笔记卡是紫色。竖线的颜色在侧栏、正文与相关面板保持一致，切换标签页不改变颜色。

### 相关面板的层级

相关面板的区块标题承担分组与定位的任务，标题字号 12.5 像素，字重 700，下方带一条细分隔线。空状态退到背景里，字号 10.5 像素，与图标并排成行。

空状态有四个形态：没有内容时是收纳盒图标，检索进行中是转圈图标，检索失败与没有命中是查找图标，引用出处为空时是引号图标。空状态只描述状态，不解释操作。

段落助手的分区标签采用相同的字号与墨色。

### 概念扩展

相关面板先按字面匹配。作者换一种说法，卡片就找不到。字面命中的数量不足时，面板补问一次：从学习集已有的用词里找出与当前段落共同出现的词，用这些词再检索一次。

补问出来的卡片排在字面命中的卡片之后，元信息行标出 `经由「扩展词」`。扩展词是卡片里的主题词，鼠标停留时说明该词与当前段落的哪一个词共同出现。正文下方的证据条与助手的依据清单采用相同的标记。

扩展词的挑选有几条限制：标签里的斜杠左边是分类名，右边才是内容，`topic/合作` 提供的内容是 `合作`。出现在太多卡片里的词不作扩展词，这类词只说明卡片属于同一门学科。过于常见的词同样不作扩展词。桥接词在学习集里找得到，出现在多张卡片里，或者出现在标题与标签里，只作为词的片段出现的字不做桥接。

### 资料库候选

段落里最长的概念词是作者正在写的内容。命中卡片没有提到这个词，学习集里也没有这个词，面板据此判断材料缺失，到 MarginNote 资料库里找出学习集以外的相关材料。

候选区块出现在相关卡片区块之后，每条候选给出标题、所属学习集与命中片段，可以定位到 MarginNote、插入正文或打开文献。段落停止输入以后才发起检索，检索词改变时重新检索。资料库里没有可用的材料时，区块不出现。

### 引用溯源

正文里的引用带有下划线。学习集里存在对应卡片时，下划线是主题色实线；学习集里没有对应卡片时，下划线是警示色虚线。标记只影响显示，文档结构与导出格式不受影响。

点击正文里的引用以后，段落末尾的浮层由证据条切换为出处卡片。出处卡片给出卡片标题、摘录片段、页码、引用键与来源文献，可以定位到 MarginNote，也可以插入正文。学习集里没有对应卡片时，出处卡片给出检索词，按检索词可以检索资料库。点击正文其他位置或者按 Esc，出处卡片关闭，证据条恢复。

侧栏的 `引用出处` 列出当前所在节的全部引用，每条给出引用文本与出处状态。缺少来源时提供 `查找` 按钮，检索词与正文里缺来源时的检索词一致。点击清单里的引用，正文移动到该引用并展开出处卡片。

正文里写下的引用，其来源卡片排在证据条与相关卡片的最前面，并标注 `引用来源`。作者先看到明确引用过的材料。

### 没有标题的卡片

MarginNote 的卡片可以没有标题。摘录卡从文档里摘来一段文字以后，卡片上只有正文，标题为空。

写作台以 MarginNote 的数据为准，不替卡片编造标题。卡片没有标题时，标题位显示文献名，文献名也没有时，标题位留空。引用出处清单里没有标题的卡片用文献名标识，正文末尾的出处卡片不显示标题行。

正文卡片块保存的是卡片快照。早期版本把正文首段当成了标题，0.11.1 按学习集里的实时卡片补齐旧快照，实时卡片没有标题时清空快照标题。

### 使用痕迹

卡片进入正文时，文稿记下这次引用。很久没有再用的卡片被检索到时会标出上次使用的时间，便于重新捡起当初读过却已经忘记的材料。

### 跨文稿知识记录

使用记录独立于单份文稿保存在本机，因此换一份文稿继续写不会重新积累。检索到的卡片如果在别的文稿里用过，痕迹会写明来自哪份文稿，例如 `《实验记录》12 天前用过`。使用次数也参与相关度打分，作者长期读过的材料更容易浮现。

### 论证覆盖

大纲面板的每一节标题都带一个证据标记，数字是该节正文里出现的卡片数量。标记为空心圆时表示这一节还没有引用卡片，面板顶部给出待补的章节数。

统计范围与大纲一致：一个标题从标题所在的位置开始，到下一个同级或更高级标题之前结束。表格、任务列表与卡片块都算正文。

### 关联网络

正文卡片的更多菜单里有 `相关卡片`。弹层沿着一张卡片列出同一条文献条目、同一篇文献、共享标签与内容相近的卡片，每条关联都写明依据。关联卡片可以直接插入正文，也可以跳回 MarginNote 查看原处。

### 段落助手

选中一段文字，浮动工具条末尾的图标打开段落助手。助手可以润色选区，可以接着往下写，也可以提炼要点。

提示词把选区与相关卡片一起交给模型，并写明只能使用卡片里的信息，因此建议不会跑出已有材料。生成结果先给作者过目，可以复制、插入到段落后方，也可以直接替换选区。

助手的依据清单与相关面板、证据条采用同一套选取规则：字面命中优先，概念扩展补足。依据带有关联路径时，材料清单里写明该卡片与段落的共同词，模型据此判断材料与段落的关系。

文稿术语改用分词接口提取，写作台的界面用语不计入术语。术语表随选区一起交给模型，模型沿用手稿既有的写法。

### 建议带出处

助手的依据区是一份清单。每一条给出编号、卡片标识、来源与原文片段，并提供 `在 MarginNote 中定位` 按钮。

提示词要求模型在引用材料的句子后面标注 `〔卡片 N〕`。建议正文里的标记显示为编号徽标。点击徽标以后，对应的依据条目高亮并滚动到视野；点击依据条目的编号，建议正文里的对应徽标同样高亮。

采纳建议时，标记转成正文引用 `[@引用键, p. 页码]`，引用随即进入引用溯源与相关面板的出处清单。卡片没有引用键时只去掉标记，不留无法解析的引用。模型没有标注依据时，建议照常显示，面板不补写依据。

### 文稿术语

助手面板里的 `文稿术语` 来自正文的用词统计。反复出现的词组被视为术语，只出现一次但足够长的词也会收录。

术语会写进提示词，模型因此沿用文稿既有的写法，不把术语替换成近义词。助手面板同时列出术语表，说明建议与手稿对齐的范围。

### 资料库检索

相关面板的 `资料库材料` 可以按当前段落检索整个 MarginNote 资料库。检索词取自证据片段里的完整词组，因此该词组一定在资料库中出现过。

结果分成卡片命中与文献命中。卡片可以定位到 MarginNote，也可以插入正文；文献可以打开到 MarginNote 的对应文档。检索由作者手动触发，不会打断书写。

模型接口与 OpenAI 兼容，默认连接本机的 Ollama 服务：

- 接口地址 `http://127.0.0.1:11434/v1`
- 模型名 `qwen2.5:3b`

面板右上角的设置按钮可以改写接口地址、模型名与密钥。密钥只保存在浏览器本地存储，不写入系统偏好。

### 演示文稿

首次启动时写作台创建内置文稿《写作台使用指南》。该文稿同时充当操作说明，逐项介绍各项功能的用法。模板更新以后，写作台按版本号替换本机上的旧版本。

### 文稿的删除

侧栏 `文稿` 标签页里的每份文稿都带一个删除按钮。删掉最后一份文稿以后，文稿列表变为空，写作台不会再补一份空文稿，正文同时不接受输入。空列表的状态保存在本机，重新打开插件以后列表仍然为空。点侧栏上方的 `新建文稿` 即可开始写。

## 图标与入口

`public/icon.png` 是插件图标，尺寸 64×64，源文件为 `assets/icon.svg`，执行 `pnpm icon` 重新生成。

MarginNote 读取图标正中心像素的饱和度：饱和度高于 0.30 时按图片的颜色绘制，否则按 alpha 蒙版绘制成单色。图标图形以外必须完全透明，中心必须是不透明的高饱和色块，并且不使用渐变与阴影。当前图标中心像素为 `#2f6f5e`，饱和度为 0.58。

插件的入口在主界面。主界面的胶囊栏提供 `输出` 模态，模态列表中的 MN Writer 是面板入口，该入口不依赖场景模板。

场景界面的入口由模板决定。`template/template.json` 的 `plugins` 列出该插件，底部工具条的 `写作` 模态包含入口 `addon.top.museday.mn.writer.primary`。图标无效时，MarginNote 不生成胶囊按钮，场景界面因此没有入口。

## 面板尺寸

MarginNote 的浮窗不能直接拖动边缘改尺寸，面板需要提供调整入口。

面板右下角有一个尺寸手柄。拖动手柄即可调整面板的宽度与高度，松手后尺寸保存在本地，下次打开面板时自动恢复。短按手柄在预设尺寸之间循环切换。手柄获得焦点以后，方向键每次调整 40 像素，按住 Shift 每次调整 80 像素。

原生侧在每次布局后校正面板位置，面板连同顶部 36 像素的拖拽条都不会进入场景顶栏的区域。高度上限按当前场景的可用高度计算，页面请求的尺寸超过上限时按上限调整，因此拖动与切换预设都不会触发面板与顶栏重合。

宽度下限是 420 像素，宽度上限取场景可用宽度，高度下限是 420 像素。

窄屏下，顶栏自动收起次要操作。`更多操作` 菜单提供卡片视图、主题、专注模式与导出入口。

## 桥接行为

面板通过 `window.mn` 读取 MarginNote 数据，调用顺序如下：

1. `GET /capabilities`：读取接口版本与单批卡片上限。
2. `GET /ui-state`：读取当前学习集标识。
3. `GET /study-sets/{id}/tree?sort=document`：分页读取脑图节点，单页 500 个节点，最多 40 页。
4. `GET /study-sets/{id}/documents`：读取文档标题。
5. `POST /notes/batch-get`：分批读取正文、批注、标签与插件字段，每批最多 200 张卡片。

`GET /context` 读取学习集标题。旧版 MarginNote 缺少该接口时，面板省略标题并继续读取卡片。

`POST /notes/batch-get` 返回的 `title` 是完整的显示标题，卡片没有标题时为空串；`preview` 是显示预览，卡片没有标题时取正文首段。面板只用 `title` 作为标题，`preview` 用于卡片没有摘录时补足正文。

面板订阅 `excerpt`、`comments`、`synced`、`undo`、`imported` 事件。面板收到事件后静默刷新卡片列表。窗口重新获得焦点时同样刷新，用于处理学习集切换。

正常连接时，侧栏底部不显示状态信息。出现异常或需要操作时，侧栏底部显示提示：

- 未打开学习集：提示先打开一个学习集。
- 连接失败：显示 MarginNote 返回的错误，并提供重试按钮。
- 卡片列表截断：提示当前学习集的卡片数量超过读取上限。
- 演示数据：浏览器环境没有 `window.mn`。

## 已知限制

- 卡片列表只覆盖当前学习集，跨学习集搜索尚未实现。
- 单批 200 张、最多 40 页属于安全上限。超过上限时，侧栏显示 `内容已截断`。
- 桥接行为依据官方接口文档实现，并通过本地模拟桥接验证。真实 MarginNote 中的入口与桥接状态仍需人工确认。
- 当前提供 Markdown 与 JSON 导出，并支持 JSON 备份恢复。Markdown 导入尚未实现。
- 行数与页数是估算值，与 Word 的分页结果不一定一致。
- 文稿保存在当前设备的应用文档目录，设置保存在系统偏好中，不提供云端同步。
